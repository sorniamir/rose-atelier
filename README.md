# ROSÉ ATELIER — فروشگاه آنلاین

فروشگاه ویترین‌محور و راست‌چین برای پوشاک، اکسسوری و عطر؛ ساخته‌شده با HTML، CSS و JavaScript خالص برای استقرار سریع روی GitHub Pages یا Vercel.

## وضعیت فعلی

- طراحی responsive و فارسی (RTL)
- کاتالوگ محصول و فیلتر دسته‌بندی/جست‌وجو
- سبد خرید با ذخیره در مرورگر
- فرم ثبت سفارش نمایشی
- نمایش وضعیت موجودی نمونه
- مسیر استقرار خودکار GitHub Pages
- طرح اولیه دیتابیس و چک‌لیست عملیاتی در پوشه docs و supabase

> **مهم:** این نسخه یک نمونه‌ی نمایشی قابل انتشار است. سفارش‌ها و سبد خرید فقط در مرورگر ذخیره می‌شوند؛ درگاه بانکی، موجودی مشترک بین کاربران، حساب کاربری امن و پنل مدیریتی production هنوز به سرویس بک‌اند و کلیدهای واقعی نیاز دارند. پرداخت واقعی انجام نمی‌شود و هیچ اطلاعات کارت بانکی دریافت نکنید.

## اجرای محلی

فایل index.html را باز کنید یا در ریشه پروژه اجرا کنید:

    python -m http.server 8080

سپس آدرس http://localhost:8080 را باز کنید.

## استقرار روی GitHub Pages

1. در مخزن GitHub به Settings → Pages بروید.
2. در بخش Build and deployment، گزینه Source: GitHub Actions را انتخاب کنید.
3. Workflow با هر push به شاخه main سایت را منتشر می‌کند.
4. آدرس نهایی در همان صفحه Pages نمایش داده می‌شود.

## استقرار روی Vercel

مخزن را در Vercel import کنید. Framework Preset را روی Other بگذارید، Build Command را خالی بگذارید و Output Directory را . انتخاب کنید.

## فعال‌سازی نسخه عملیاتی

قبل از فروش واقعی، موارد زیر باید انجام شوند:

1. ساخت پروژه مستقل Supabase برای فروشگاه (به پروژه‌های نامرتبط وصل نشوید).
2. اجرای migration پایگاه داده و تنظیم RLS مطابق چک‌لیست.
3. پیاده‌سازی API/Edge Function سمت سرور برای محاسبه مجدد قیمت، رزرو اتمیک موجودی و ایجاد سفارش.
4. اتصال احراز هویت امن و محدودسازی پنل ادمین به نقش مدیر.
5. اتصال درگاه پرداخت متناسب با کشور/شرکت پذیرنده و بررسی callback سمت سرور.
6. تنظیم دامنه، سیاست حریم خصوصی، قوانین مرجوعی، ارسال و مالیات.
7. جایگزینی محصولات/تصاویر نمونه با کاتالوگ و محتوای دارای مجوز شما.

- supabase/migrations/202610140001_store_schema.sql — طرح اولیه جداول و سیاست‌های RLS

## مجوز

کد پروژه برای سفارشی‌سازی همین فروشگاه ارائه شده است. تصاویر نمونه از منابع خارجی بارگذاری می‌شوند؛ پیش از انتشار تجاری، مجوز و شرایط استفاده هر تصویر را بررسی و در صورت نیاز با تصاویر متعلق به برند جایگزین کنید.
